name: circuit-wire-pairs
description: 从电气原理图读取原始器件符号、端点角色与等电位网络，交给程序映射实体触点。
---

你只负责读图。按导线连续性读取整图，覆盖主回路、控制电源两极、按钮机械联动的两副触点、自锁、互锁及线圈返回。虚线机械联动不导电。沿每个线号逐段找出同网的所有端点，保留盘外和辨认不清的端点，分支不得拆成若干双端网络。不同网络不得重复使用同一端点。相同线号只出现一次。请不要预测盘上跳线，不要提供接线答案。

输出 JSON：{"title":"图名","nets":[{"line":"原线号（无则逐网编号）","ends":["原位号:端点角色", "..."]}]}。
器件用图上的实际位号，QF、QS、XT、电机、电源独立保留。单只未编号的 KM/SB/FR 保留原位号。端点角色约定：
- 每个 NO 或 NC 触点按静止状态判读，两端写 NO.in、NO.out 或 NC.in、NC.out；in 为上游，out 为下游。若同一器件有第二副相同性质的辅助触点，使用图上实际端子号，无标注时标 unknown 加位置。
- 接触器线圈用 coil.in、coil.out。三极主触点、熔断器、热元件按图面该器件从左至右的极序写 p1.in、p1.out、p2.in 等；输入侧和输出侧按器件区分，换相以导线实际走向为准。
- 确实印出的实体端号也可直接使用；器件旁的导线号不是端号。来源不明记录 unknown 加位置。按触点两边分别追踪，不能把触点本身当成一根导线。
